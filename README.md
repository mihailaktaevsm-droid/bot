# Учёба — ежедневник студента МГТУ им. Баумана

Приложение для iPhone: пары из ЛКС, домашка по предметам и обычные дела
(«зайти в деканат», «позвонить родителям»). Работает без интернета, все данные
хранятся на телефоне.

## Что умеет

- **День** — пары на сегодня (текущая подсвечена, окна между парами видны),
  номер недели и числитель/знаменатель, дела и домашка на этот день, просроченное.
  Листай дни свайпом влево/вправо или по полосе недели.
- **Домашка** — электронный журнал: по сроку (просрочено / к сегодня / к завтра / …)
  или по предметам. Нажми на пару → «Добавить ДЗ», и срок сам поставится на
  следующую пару по этому предмету.
- **Расписание** — вся неделя, переключатель числитель/знаменатель, можно
  добавить или исправить пару вручную.
- **Ещё** — группа, начало семестра, обновление расписания, резервная копия.

## Как поставить на iPhone (один раз)

1. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**,
   выбрать ветку с приложением и папку `/ (root)`, нажать **Save**.
   Через минуту сайт будет доступен по адресу
   `https://mihailaktaevsm-droid.github.io/bot/`.
2. Открыть этот адрес на iPhone в **Safari**.
3. Нажать «Поделиться» → **«На экран «Домой»»** → «Добавить».

## Расписание из ЛКС

Файл `schedule.json` каждый день обновляет GitHub Actions
(`.github/workflows/schedule.yml` → `scripts/fetch_schedule.py`), приложение
подхватывает его само. Первый раз можно запустить вручную:
**Actions → «Обновить расписание» → Run workflow**.

Другая группа — укажи её при ручном запуске или заведи переменную `GROUP`
в **Settings → Secrets and variables → Actions → Variables**. Если группа не
находится по названию, добавь переменную `GROUP_UUID` (код из ссылки на
расписание в ЛКС).

Если ЛКС недоступен с серверов GitHub, расписание можно вставить прямо в
приложении: «Ещё» → «Ссылка ЛКС» → «Открыть расписание в ЛКС» → скопировать
текст → «Вставить расписание». Или добавить пары вручную.

## Файлы

| Файл | Что это |
| --- | --- |
| `index.html`, `css/style.css`, `js/app.js` | само приложение |
| `manifest.webmanifest`, `sw.js`, `icons/` | установка на экран «Домой» и офлайн-режим |
| `schedule.json` | расписание (обновляется автоматически) |
| `scripts/fetch_schedule.py` | загрузка расписания из ЛКС |
